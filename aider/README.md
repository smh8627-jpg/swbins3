# 로컬 코딩 에이전트 (Aider + Ollama)

`ai-tools-hub`의 "코드/앱" 탭은 텍스트 한 덩어리만 생성하는 단발성 호출입니다. 파일을 직접 읽고 쓰고, 명령을 실행하고,
에러를 보고 스스로 고치는 "클로드 코드 같은" 반복 작업이 필요하면 이 폴더의 [Aider](https://github.com/Aider-AI/aider)를 씁니다.

⚠️ **이건 웹 UI가 아니라 터미널 도구입니다.** LLM이 파일을 쓰고 명령을 실행하는 걸 브라우저 버튼 클릭으로
트리거하는 건 안전하지 않아서, 사람이 터미널에서 직접 실행하고 지켜보는 구조로 만들었습니다.

## 사용법

1. 작업할 프로젝트 폴더로 이동 (git 저장소 권장 — Aider가 변경사항마다 자동 커밋함)
2. `C:\swbins3\aider\dev-agent.bat` 실행
3. 프롬프트에 하고 싶은 작업을 한글로 입력 (예: "README에 설치 방법 추가해줘", "이 버그 고쳐줘")

## 품질에 대해

로컬 7B 모델(qwen2.5-coder:7b)이 실제 코드를 쓰기 때문에 클로드 코드보다 실수가 훨씬 많고,
복잡한 멀티파일 작업이나 애매한 요구사항 추론에 약합니다. 간단한 작업·오프라인/무료 대체용으로 쓰세요.
중요한 작업은 항상 diff를 검토하고, git으로 커밋된 상태에서 실행해서 언제든 되돌릴 수 있게 하세요.

## 다른 모델로 바꾸기

`dev-agent.bat`의 `--model ollama_chat/qwen2.5-coder:7b` 부분을 다른 Ollama 모델로 바꾸면 됩니다.
더 큰 모델(예: `qwen2.5-coder:32b`, VRAM 넉넉하면)일수록 품질이 좋아집니다.
